## 1.0.0 (2026-10-19)

### Features

- `/api/stars` endpoint that renders an SVG card of the stars a GitHub user or organization has
  earned, ready to embed in a profile README with a single Markdown link.
- Four layouts: `overview` (total, forks, repos, followers, top repo and a language donut),
  `repos` (most starred repositories as animated bars), `compact` and `badge`.
- 20 themes including gradient themes and an `auto` theme that follows the viewer's light or
  dark mode, plus per-colour overrides (`bg_color`, `title_color`, `accent_color`, …).
- Options to hide the title, border or individual stats, exclude repositories, include forks,
  set a custom title, border radius and cache lifetime.
- Subtle CSS animations that respect `prefers-reduced-motion`, with `disable_animations` to
  turn them off.
- GitHub GraphQL API support with an unauthenticated REST fallback.
- Friendly, on-theme error cards so READMEs never show a broken image.
- In-memory and CDN caching, and an optional `ALLOWED_USERNAMES` allowlist for personal
  deployments.
- Interactive link builder on the deployment's home page.
- GitHub Action and CLI to render cards without hosting anything.
- Requires Node.js 22 or newer.
